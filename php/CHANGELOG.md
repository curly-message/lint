# Changelog

## 1.0.0

The first version: the `curly-lint` command of the Rust crate
`curly-message-lint` 1.0.0, as the Composer package `curly-message/lint`,
which holds the command built for Linux and macOS, each on x86-64 and on
ARM64, and for Windows on x86-64, and a launcher in PHP that Composer puts
in a project's `vendor/bin/`.
